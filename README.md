# ريم — السكرتيرة الخاصة

سكرتيرة شخصية لـ **سالم الجابري** (مسقط، سلطنة عُمان) لتنظيم:

- **المواعيد**: تصوير، اجتماعات، زيارات زبائن
- **الطلبات والشغل**: تصميم، إعلانات، مونتاج مع موعد التسليم
- **ملخص يومي**: مواعيد اليوم والطلبات المفتوحة والمتأخرة

## التشغيل
افتح الرابط من Safari على الآيفون، ثم **مشاركة ← إضافة إلى الشاشة الرئيسية** لتصير مثل التطبيق.

البيانات تُحفظ على الجهاز نفسه (localStorage).
