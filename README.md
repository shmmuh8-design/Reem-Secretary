# ريم — السكرتيرة الخاصة

سكرتيرة شخصية لـ **سالم الجابري** (مسقط، سلطنة عُمان). تشتغل على الجوال بدون إنترنت وبدون أي خدمة خارجية.

- 🎙️ **تسمعك وتتكلم:** «ذكريني بكرة الساعة 5 العصر أتصل بأحمد»، «شو عندي اليوم؟»، «خلصت تصميم المطعم»، «كم الساعة؟»
- 📅 **المواعيد والطلبات** مع تذكير قبل الموعد
- 🔔 **إشعارات** إعلان الساعة، والريوق والغدا والعشا، وملخص الصبح والمسا
- 📲 **سيري:** اختصار باسم «ريم» يفتح `reem://talk` — أو `reem://say?q=النص`

## تطبيق الآيفون
مجلد `ios-app` (Capacitor 7) ويُبنى على Codemagic من `codemagic.yaml` (workflow: `reem-ios`) ثم يوصل TestFlight.

## نسخة المتصفح
افتح الرابط من Safari ← مشاركة ← إضافة إلى الشاشة الرئيسية.

البيانات تُحفظ على الجهاز نفسه.
